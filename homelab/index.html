A self-hosted Linux server, set up at the local command line and administered remotely over SSH ever since — no GUI, no control panel. It runs multiple private Minecraft servers for friends and family, secured with firewall rules and a private mesh network rather than exposed to the open internet.

linux ssh ufw / iptables tailscale self-hosting
$cat overview.txt

The server is headless — no desktop environment, no monitor attached day-to-day. Initial OS installation and setup happened directly at the machine's own command line; every task since, from package installs to firewall changes to running multiple concurrent Minecraft server instances, is done remotely over SSH.

Rather than port-forwarding and exposing the box directly to the internet, remote access runs over a private Tailscale mesh network, with UFW and iptables enforcing a strict default-deny stance on top. The server is reachable to people who are supposed to reach it, and effectively invisible to everyone else.

Nothing reaches the box directly from the public internet — every connection, admin or player, comes in over the Tailscale mesh first. UFW and iptables rules then gate what's reachable even on that private network, so a compromised device on the mesh still doesn't get a free pass to everything running on the server.

$history | grep practices
  • Command-line first, then remote. Initial setup happened at the machine's local command line; every task since — service management, troubleshooting, firewall changes — happens remotely over SSH. No GUI tools, no control panel software.
  • Private networking over port-forwarding. Tailscale creates a mesh VPN between the server and authorized devices, so remote access doesn't depend on opening inbound ports to the public internet.
  • Defense in depth at the firewall layer. UFW and iptables rules restrict traffic even within the private network, rather than treating "on the mesh" as automatically trusted.
  • Multiple isolated services on one host. Several dedicated Minecraft server instances run concurrently for different groups, without interfering with each other.
